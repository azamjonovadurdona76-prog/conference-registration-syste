# conference-registration-syste# 🎓 Ilmiy-Amaliy Konferensiya Ekotizimi

Talabalarning ilmiy-amaliy konferensiyasini avtomatlashtirish, ro'yxatdan o'tkazish va qatnashchilarni real vaqt rejimida zamonaviy veb-interfeysda kuzatish uchun mo'ljallangan bulutli veb-ilova.

---

## 🛠 Tizim Arxitekturasi va Texnologiyalar
Loyiha quyidagi texnologiyalar yordamida qurilgan:
* **Frontend:** HTML5, Tailwind CSS (Zamonaviy dizayn va kartochkalar)
* **Backend & API:** Google Apps Script (`Code.gs`)
* **Ma'lumotlar bazasi:** Google Sheets (`Qatnashchilar`, `Hakamlar` varaqlari)
* **Hosting / Versiyalash:** GitHub & GitHub Pages

---

## 🚀 Loyihaning Ishlash Prinsipi
1. Foydalanuvchi GitHub Pages orqali ochilgan veb-saytdagi **Ro'yxatdan o'tish formasi**ni to'ldiradi.
2. Kiritilgan ma'lumotlar **Google Apps Script API** orqali avtomatik ravishda **Google Sheets** bazasiga yoziladi.
3. Veb-sayt real vaqt rejimida bazadagi ma'lumotlarni o'qib, ularni chiroyli kartochkalar ko'rinishida ekranda namoyon qiladi.

---

## 📂 Fayllar Tuzilmasi
* `index.html` — Foydalanuvchi interfeysi, ro'yxatdan o'tish formasi va ma'lumotlarni chiqarish qismi.
* `Code.gs` — Google Sheets va veb-sayt o'rtasidagi ma'lumot almashinuvini ta'minlovchi backend skripti.
